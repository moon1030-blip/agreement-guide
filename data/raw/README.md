# 공개 자료 원문 정리 (PLAN 2번)

이 폴더에는 **이미 외부에 공개된 자료만** 넣는다. 대외비 협약서(본문·별첨)는 절대 넣지 않는다.

## 정리 규칙

- 자료 1개 = 파일 1개 (`.md`). 파일 이름은 영문 소문자와 하이픈으로 쓴다 (예: `faq.md`, `fsc-2026-06-25.md`).
- 파일 맨 위에 자료 정보를 적고, `## 제목` 하나를 항목 1개로 본다. 앱은 이 항목 단위로 근거를 찾고 보여준다 (PLAN 3번에서 `data/chunks.json`으로 변환).
- 항목 제목은 화면에 "근거 출처"로 그대로 보이므로, 원문의 질문·소제목을 그대로 쓴다.
- 본문은 원문을 그대로 옮기고, 요약하거나 고치지 않는다. 표는 문장이나 목록으로 풀어 쓴다.
- 기준일은 자료에 적힌 날짜(보도자료 배포일, 공지 게시일)를 쓴다. 날짜가 없으면 옮겨 적은 날을 쓴다.
- 사람 이름, 연락처 같은 개인정보가 있으면 빼고 옮긴다.

파일 형식은 [`_template.md`](_template.md)를 복사해서 쓴다.

## 옮기기 전에 확인할 것

- 홈페이지·보도자료 화면에 이용 조건(공공누리 표시 등)이 있는지 확인한다. 이번 실습은 내부 업무용이지만, 조건이 있으면 그 조건을 따른다.
- 첨부파일(PDF·한글)로만 있는 보도자료는 본문 중 새출발기금 내용만 옮긴다.
